# The Glass Alibi — Player Package

**Players:** 2  
**Estimated playtime:** 90–150 minutes (approximately two hours)  
**Mode:** cooperative investigation with split scenes and joint regroups

## Before you begin

1. Read **only** files in this `PLAYER/` folder.
2. Do not open `DO_NOT_READ/` or any repository path outside `PLAYER/`.
3. Assign roles using `SETUP.md`.
4. Follow scene codes in order. Do not read ahead in any booklet.

## Package contents

| File / folder | Purpose |
|---|---|
| `SETUP.md` | Preparation, printing, role assignment |
| `HOW_TO_PLAY.md` | Rules, checks, time, communication |
| `NAVIGATION_INDEX.md` | Scene code reference (no story spoilers) |
| `CHARACTERS/` | One character sheet per investigator |
| `SHARED/` | Case file, clue log, worksheets |
| `JOINT_SCENES.md` | Scenes both players read together |
| `BOOKLET_SYSTEMS.md` | Private scenes — systems / automation track |
| `BOOKLET_FIELD.md` | Private scenes — field / perimeter track |
| `ENDINGS.md` | Outcome pages (open only from `J-900`) |
| `COMPILATION_REPORT.md` | Package metadata (no plot) |

## Quick start

1. Complete setup in `SETUP.md`.
2. Both players open `JOINT_SCENES.md` at **J-100**.
3. When directed, each player opens their private booklet at the listed code.
4. Regroup at **J-150** and **J-300** before continuing private tracks.
5. Finish at **J-900** and turn to the matching ending in `ENDINGS.md`.

Good luck. The report locks at **00:30**.
