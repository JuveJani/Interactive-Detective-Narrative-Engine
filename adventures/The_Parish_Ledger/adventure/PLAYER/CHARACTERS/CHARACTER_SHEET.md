# Character sheet — Diocesan finance auditor

You audit parish financial records and verify ledger-deposit reconciliation for diocesan review.

## Check modifiers

| Capability | Modifier | When it applies |
|---|---|---|
| **Reasoning** | **+2** | Ledger cross-reference and records reconstruction checks |
| **Technical** | **+2** | Bank deposit reconciliation and financial system checks |
| **Perception** | **+1** | Document alteration and physical record inspection checks |

Auditor tablet, document camera, reconciliation worksheets, parish policy manual.

File a supported reconciliation report before the 1700 deadline.
